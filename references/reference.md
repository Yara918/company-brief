# company-brief · 详细规则（按需加载）

## A. 分层查询规则（写进检索清单，用户可见）

**社媒（公司号）**：
- 必查 5：微博 / 抖音 / 小红书 / 领英 / X
- 按行业查：快手（泛娱乐/直播）· B站（科技/年轻人）· 视频号（微信生态）· 知乎（知识/科技）· 脉脉（职场）· Facebook/Instagram/YouTube（有海外业务时）
- 每平台独立查询，命中写【账号名 + 粉丝数 + 美观链接按钮】，查不到写「未检索到 + 检索记录」
- **链接必须是账号主页**：社媒区按钮只允许指向该平台的账号主页（如 weibo.com/u/xxx、douyin.com/user/xxx、linkedin.com/company/xxx）。
- **报道 ≠ 账号**：只查到新闻报道提及账号存在、但主页未检索到时，写「未检索到账号主页，仅见报道提及」并把报道链接放检索记录，**禁止把报道链接当社媒主页按钮**。

**招聘**：
- 必查：BOSS直聘 / 猎聘 / 智联 / 前程无忧 / 官网招聘页
- 按行业查：58同城（蓝领/服务）· 拉勾（互联网）· 牛客/应届生网（校招）· LinkedIn Jobs/Indeed/Glassdoor（海外）
- 真查：每平台独立搜，命中写【岗位 + 平台链接】，全查无写「各平台均未检索到 + 检索记录」

## B. 内容字段字数上限

| 字段 | 上限 |
|---|---|
| 公司一句话 | ≤ 40 字 |
| 3 个关键数字（体量/采购/财务） | 各 ≤ 60 字，带来源 |
| 公司快照每行 | 各 ≤ 80 字，带来源 |
| 招聘信号 | ≤ 80 字，带平台链接 |
| 风险每段（事实/依据/对我方） | 各 ≤ 50 字 |
| 会面话题（3 个） | 各 ≤ 60 字 |

- 3 个关键数字限定：① 体量（营收/员工/用户）② 规模（年采购额/供应商/在招采购岗）③ 财务健康（净利/毛利/融资）——禁止凑数，查不到写「未检索到」。
- **KPI 必须是数字（硬性）**：3 个关键数字每个都必须是大数字/数量（如「95.6万粉」「在招采购岗3名」「净利率9%」）；**禁止填文字结论**（如「面包品类已跑通」）；规模查不到确切数字时用数量表述（在招岗位数/供应商数/单品销售额），实在没有才写「未检索到」。

## C. 社媒链接呈现（美观，不裸链）

```
命中账号 → 美观平台卡片：
  [平台图标] 账号名（粉丝 xxx） [进入主页→按钮链接]
查不到 → 「未检索到（环境限制可在 App 内搜索账号名）」+ 检索记录
禁止：裸 URL、纯文字「来源：xxx」
```

## C2. 渲染约定（report-template.html 填充）

- 来源一律填成按钮链接：`<a class="srclink" href="真实URL">来源</a>`，禁止裸 URL；**按钮文字必须描述来源**（官网·关于我们/2025年报（巨潮）/企查查/BOSS直聘等），禁止统一写「来源」「来源1」「来源2」。
- 社媒区 `{{sm_rows}}` 按表格行填：`<tr><td>平台名</td><td><span class="uname">账号名</span><span class="fans">粉丝数</span></td><td><a class="btn" href="真实URL">进入主页</a></td></tr>`；未检索到 → 同结构，账号格写「未检索到」，操作格留空。
- **社媒按钮必须是账号主页链接**（weibo.com/u/xxx、douyin.com/user/xxx、linkedin.com/company/xxx 等），**且必须来自检索结果原文**，禁止按 ID 格式推测编造；只查到报道提及 → 写「未检索到账号主页，仅见报道提及」，报道链接放检索记录，**禁止把报道链接当社媒主页按钮**。
- **内容点来源完整性**：速读卡/快照每行/招聘/风险（事实/依据/对我方）/话题/Fit 每一条都必须带可点来源；缺来源 → 补来源或写「未检索到出处」，禁止裸内容。
- **Fit 评估渲染**：放在会面话题内、话题③之后（「Fit 评估：这单合作值不值得谈：徽章 强/中/弱 + 理由」），**不带来源**；结论与理由方向必须一致（强→理由支撑强，弱→理由说明不宜投入）。
- 内容字段里的空白占位：查不到写「未检索到」，来源按钮给真实检索记录链接。

## D. 免责声明（措辞各自贴切）

- 社媒区：`社交账号基于公开检索结果整理，受各平台可见性、登录墙与检索覆盖限制，账号无法保证收录完全，仅供会前参考；未检索到 ≠ 不存在。`
- 招聘区：`招聘信息基于公开平台检索整理，受各平台收录范围、更新时效与地区差异限制，在招岗位无法保证收录完全，仅供会前参考；未检索到 ≠ 当前无招聘。`

## E. 检索记录（透明可复核）

```
附录写「已检索平台 / 未检索到平台 / 检索记录」：
  已检索：微博✓ 抖音✓ 小红书✓ 领英✓ X✓ BOSS直聘✓ 猎聘✓ 智联✓ 51job✓ 官网招聘✓
  未检索到：快手（该行业少用）· 58（非蓝领行业）· …
  检索记录（每条 = 平台×关键词×结果）：
    微博：搜"公司名" → 无官方账号
    抖音：搜"公司名" → 无官方账号
    BOSS直聘：搜"公司名" → 命中公司主页（链接）
→ 用户打开复核：平台真查过、分类理由可解释
```

- **来源不重复**：同一 URL 全报告最多出现 2 次；**降级场景例外**：同一官网 URL 最多 3 次，且必须至少配 1 个非官网来源，禁止全篇只用一个来源；超出即换替代来源或如实标注。
- **登录墙/403 标注**：企查查/启信宝/天眼查等工商平台及反爬站点引用时，链接文字标注「需登录」或「访问受限」，并优先配一个免登录来源（官网/新闻/百科）；渲染前逐条自检，拿不准的链接不引用。
